Scientific and statistical caveats

  • Locally measured hide-and-recover performance on mapped faults is a proxy, not a calibrated estimate or confidence interval for the organizer's expert-labeled test set.
  • The relative merits of sparse dots and catalogue collars are hypotheses. Under the official max-kernel DTI, removing redundant predictions may reduce false-positive weight without reducing true-positive credit, but it may also remove useful coverage. The private test labels are unavailable, so a causal explanation of a reported score cannot be verified.
  • Owner-mirror derived rasters may have unknown preprocessing, provenance, coverage, licenses, and hidden-label contamination. SHA-256 pinning detects changes to those bytes, not whether their scientific origin or license is correct.
  • The prior portal message, “Predicted values must be in range [0, 1],” cannot be causally diagnosed without the exact uploaded bytes and a submission-page receipt. The old writer required all-finite [0,1] values and wrote zeros outside the footprint; the official public format calls for null/NaN outside. The shared writer now emits NaN/nodata outside, checks finite [0,1] values inside, and rejects infinities, in-footprint NaNs, out-of-range values and positive exterior predictions. A synthetic local TIFF passes this contract; the legacy TIFF fails it. This is a format correction, not proof of portal acceptance or the cause of the earlier error.
  • The owner-mirror sample has 60,988 positive cells that exactly equal the mapped catalogue support; the official problem page describes a total-absence sample. The shape/grid mask remains useful for local testing, but this semantic inconsistency and the unauthenticated mirror origin must be resolved before interpreting it as the organizer template.
