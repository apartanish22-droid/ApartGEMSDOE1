How to submit on DrivenData

  1. Download the newly approved file.
    Use the exact filename and SHA-256 in that future run card. The research file above is not that file.
  2. Open the competition.
    Sign in to DrivenData, open the submissions page, and check the current weekly cap and available slot.
  3. Choose the file.
    Upload the single-band GeoTIFF using the submission form, if the current portal instructions permit it. Use the authenticated organizer template and current rules to verify the grid and outside-bounds policy.
  4. Use the future run card’s note.
    Paste its distinct comment of at most 140 characters into the optional Note field; the filename identifies the file. Do not reuse this negative audit’s note as an approval.
  5. Record the receipt.
    Only the submission-page result tied to the file hash is an ORGANIZER-CONFIRMED score. A local holdout or a public team standing is not a receipt for this file.
