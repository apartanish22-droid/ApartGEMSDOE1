WHEN A FILE PASSES

The upload checklist.

These are instructions for a future, separately selected file—not permission to upload the current research artifacts.

01

Confirm every automated gate

Check the saved surface and final dots against the complete registry, every feature-only leakage canary, and a buffered whole-component holdout against a matched best. A format pass alone is not enough.

02

Check the exact file

Validate a single-band float32 GeoTIFF, CRS, shape and transform against the authenticated organizer template; inspect all prediction values for the [0, 1] range. The local all-finite/zero-exterior policy is conservative and does not guarantee portal acceptance.

03

Confirm eligibility and quota

The published rules say three submissions per week; the remaining account-specific quota is unknown here. A separate selector must approve the candidate. Review the rules and AI-use disclosure requirements.

04

Submit the selected file

Sign in to DrivenData, choose Submit → Make new submission, select the approved .tif, and add the generated short note (at most 140 characters). No filename or note is assigned to this negative run.

05

Save the receipt

Record the submitted file’s SHA-256, exact note, timestamp and organizer receipt. Only then may that result be labeled ORGANIZER-CONFIRMED; keep the public and private rounds distinct.

Known limitations. Organizer data and individual receipts require authentication; the full parallel registry is not present in this checkout.
