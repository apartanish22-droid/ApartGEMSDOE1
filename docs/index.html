03 / Mechanism, not proof

Why did GEMSDOE32 stand out?

The user reports 0.2778 for B2, but no submission-page receipt is present. Our pixel audit shows B2's dots equal the GEMSDOE25 dot set after removing points within two pixels of the mapped-fault catalogue.

The official metric credits each truth pixel by its best nearby prediction. Pruning redundant dots may reduce false-positive mass while retaining that credit, but it can also lose useful coverage. Hidden labels prevent a causal conclusion or a justified claim of improvement.

04 / Holdout correction

Local evidence is not a leaderboard score.

The previous run recorded HOLDOUT-DTI 0.1174 [0.0994, 0.1361] (gems57-pooled-hide-v2, 11,360 withheld positives, 95% CI). That historical result is not comparable to the corrected evaluator and has not been rerun here.

The previous mask also excluded catalogue cells removed from the model’s visible context by the buffer. The shared v3 evaluator now masks only visible catalogue pixels; buffer-removed cells remain unlabelled and are conservatively counted if predicted.

Evidence before another slot
