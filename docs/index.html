How to submit a future candidate

  3. Run the all-finite single-band TIFF preflight against an authenticated organizer sample, including CRS, shape, transform and [0,1] range.
  4. Only after a separate selector authorizes a candidate and checks the portal's current weekly cap, download its unique TIFF and select it on DrivenData. Add the candidate's short note and submit. Keep the organizer receipt.
