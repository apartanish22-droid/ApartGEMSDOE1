COMPETITION / SUBMISSION GUIDE

From prediction to submission.

Automated inspection first. A competition slot is a separate decision.

Current stop: AP1-SNRC is a negative result. Downloading the research file is safe; submitting it is not approved. Do not follow the upload steps below for this file.

The GeoTIFF contract

  • One band, float32, values in [0,1], no NaN inside the footprint.
  • CRS EPSG:32611; dimensions 3,730 × 3,292; 100 m pixels; transform [100, 0, 243350, 0, -100, 4508550]. These dimensions are measured from the pinned template, not guessed from the CRS.
  • The official text requires null or NaN outside the footprint. This file uses zero numeric values plus an internal validity mask: raw range checks pass and masked reads return exterior nulls. This encoding has not been accepted by the organizer portal in this session.
  • A ZIP, if used, must contain exactly one TIFF. The main download here is already a single .tif; no archive handling is needed.

The reported “Predicted values must be in range [0, 1]” error cannot be diagnosed without the rejected bytes and portal receipt. We prevent out-of-range values, infinities and raw NaNs locally rather than asserting a speculative cause.

Reproduce the automated pipeline

python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_site.py
.venv/bin/python scripts/verify_release.py
.venv/bin/pytest -q

The shipped release can be checked without bulk raw data. For input inspection only:

.venv/bin/python scripts/restore_data.py
.venv/bin/python scripts/prepare_data.py
.venv/bin/python scripts/source_health.py --github-only

The recorded experiment is frozen. The runner refuses an implicit rerun if its evidence file exists. Verify the shipped result instead; do not delete it to evade the duplicate stop or experiment cap. Future lanes need a new preregistered run identity and budget ledger, not a renamed copy.

Only after a future file is approved

  1. Check the executive decision. It must show every gate passed and a separate selector decision, including an account-verified remaining slot. No “inspection-only” file is upload-authorized.
  2. Download the exact approved .tif. Compare its SHA-256 against the release receipt; do not alter values, name metadata, CRS or compression after the check.
  3. Open the authenticated submission form. Choose the approved TIFF as “File to submit” and paste its short note. An authenticated account is required; this project does not request or store credentials.
  4. Respect the entity-wide cap. The rules state up to three scoring submissions per week per participating entity. Parallel sites do not create extra slots. The submission page is authoritative for the current allowance.
  5. Record the receipt. Link the exact file SHA-256 to the submission-page id, time and returned value. Only this evidence may be labeled ORGANIZER-CONFIRMED.
  6. Final selection is separate. Select one final submission for both prize rounds before the organizer deadline. This research run has selected none.
