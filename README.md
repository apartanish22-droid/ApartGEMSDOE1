## Research shortlist (untested; ordinal judgment, not projected scores)

Existing feature families include updip gravity/magnetic tilt, scarp/drainage, thermal alteration and visible relay. The following are distinct proposed tests, not verified novel across other sites or necessarily obtainable in this sandbox. None was run: the prompt does not supply a single unambiguous new method paragraph and the necessary stack/registry is missing.

| Rank / expected opportunity, cost | Layers and signature | Rationale and confounder | Status |
|---|---|---|---|
| 1 / uncertain, medium | GeoDAWN magnetic and radiometric grids: local *cross-gradient phase coherence* at multiple scales, rather than existing tilt magnitude + K/Th | Coincident lithologic boundaries under cover could reveal unmapped discontinuities; lithologic contacts can mimic faults. | Requires cached bands and metadata; [USGS GeoDAWN](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and). |
| 2 / uncertain, high | 3DEP DEM: drainage channel longitudinal-profile knickpoint alignment, not the existing scarp tensor | Coherent cross-channel base-level disruptions may indicate displacement missed by mapped scarps; resistant bedrock and climate produce knickpoints. | Needs raw DEM; [USGS 3DEP](https://www.usgs.gov/3d-elevation-program); availability not checked here. |
| 3 / uncertain, high | InSAR displacement time series: spatial gradient of multi-year line-of-sight velocity | Deformation discontinuities could indicate active blind structures; groundwater extraction causes similar signals. | Needs suitable processed official displacement data and coverage verification, e.g. [NASA OPERA](https://www.jpl.nasa.gov/go/opera/); not checked or yet viable. |
| 4 / uncertain, high | Gravity and magnetic grids: multi-scale mismatch between independently estimated boundary depths | Potential-field contrasts at different depths could suggest buried structural juxtaposition; nonfault intrusive contacts can mimic it. | Requires documented inversion/uncertainty and GeoDAWN coverage, not currently verified. |

Ranking is a research priority, not a predicted DTI gain. Sources above are starting points, not verified evidence that these particular transforms detect faults. User asks for autonomous investigation, but access limitations and the experiment budget do not justify fabricating validation.

## Standing Reference: Original Competition Task & Protocol Specification

At the start of each session review this README and the user's full request in the conversation. Goal: an independently generated, unique, high-performing GEMS GeoTIFF, obvious status and one-click download only when cleared; preserve auditable evidence, official sources, and limitations. Apply Maximize P(Win) and Own the Outcome without overstating evidence.

Parallel-run rules: one specified method lane; stop for surface/final rank correlation >0.90 or dot overlap >70% within 3 pixels against any registry raster. Reuse the shared feature stack, evaluator and writer. Hide whole fault segments with buffer, derive catalogue features only from visible faults, mask visible faults exactly, and score pooled DTI with alpha 0.2, beta 0.8 and 300 m triangular kernel. Test each feature alone; AUC >0.90 is a leakage warning. Label measured results HOLDOUT-DTI (version, positive count, CI) or ORGANIZER-CONFIRMED (receipt); user-reported values are explicitly unverified. Supply a JSON run card with hypothesis, mechanism, non-fault mimic, holdout and CI, uniqueness, raster hash, validator, name/note and verdict. Cap at three experiments or two hours. Promotion to an actual submission is a separate selector step. Validate format and range without manual inspection; do not copy an old file as a new submission.
