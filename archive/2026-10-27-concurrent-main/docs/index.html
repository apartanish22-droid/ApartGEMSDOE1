3⁽ How a submission is made

  1. Place training_features.tif, labels.tif, sample_submission.tif (DrivenData data tab, login required) in data/.
  2. bash scripts/download_competition_data.sh then python scripts/prepare_data.py.
  3. python scripts/generate_submission.py produces a unique TIF + JSON receipt.
  4. python scripts/validate_submission.py file.tif data/sample_submission.tif runs the automated gate: [0,1] range, no NaN, CRS/shape/transform match.
  5. python scripts/evaluate_holdout.py computes hide-and-recover holdout-DTI (alpha 0.2, beta 0.8, 300 m triangular kernel). Upload only if it beats the repo best with paired 95% CI > 0.
  6. Upload the .tif (or a single-TIFF .zip) at DrivenData submissions, with a unique name and a note (≤140 chars).
